To configure this module, you need to:

1.  Go to *Settings \> Integrationen \> Label-Printers*
2.  Add at least one printer as default
3.  If using stock or mrp modules, make sure that the connection modules
    zrp_printer_mrp / zrp_printer_stock are available.
4.  Best used in combination with a further module, that provides
    layouts for printers, otherwise default-layouts will be used.
