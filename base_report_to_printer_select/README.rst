This module lets the user choose the printer at print time. It adds the
**Ask the user** behaviour to the printing actions of
**base_report_to_printer**: when a report configured that way is
printed, a dialog lists the printers that can handle it and one click
sends the job to the selected one. Printers declare the paper formats
they support, so only the printers matching the paper format of the
report are offered, and the last printer picked by each user for each
report is proposed first.

Configuration
=============

To configure this module, you need to:

1. Go to *Settings > Technical > Printing > Printers* and fill in
   **Paper formats** on each printer with the formats it can print. A
   printer with no paper format accepts any report.
2. Make sure the reports that should ask for a printer have the right
   **Paper format** on their *Advanced Properties* tab. This module
   shows the field on text reports too, so label reports (ZPL) can carry
   a dedicated paper format (for example a 4x6" one) that is also set on
   the label printers. A PDF report without a paper format uses the one
   of the company; a text report without one accepts any printer.
3. Go to *Settings > Technical > Printing > Reports*, open a report and
   set its **Default Behaviour** to a printing action of type **Ask the
   user**. The type is also available on the *Specific actions per user*
   lines and as the default printing action of a user.

Usage
=====

1. Print a report whose behaviour is **Ask the user**.
2. A dialog lists the printers supporting the paper format of the
   report. The printer used the last time is highlighted and focused, so
   pressing Enter prints on it again.
3. Click a printer to send the job to it. **Download** gets the file in
   the browser instead and **Cancel** does nothing.

The dialog is shown even when a single printer matches, so the user can
still download the report. **See more** reveals the printers that do not
support the paper format, for the odd case where one of them is wanted
anyway. When no printer exists at all, the report is downloaded as
usual.

======================

  the selected printer.
