1.  Print a report whose behaviour is **Ask the user**.
2.  A dialog lists the printers supporting the paper format of the
    report. The printer used the last time is highlighted and focused, so
    pressing Enter prints on it again.
3.  Click a printer to send the job to it. **Download** gets the file in
    the browser instead and **Cancel** does nothing.

The dialog is shown even when a single printer matches, so the user can
still download the report. When no printer matches, the report is
downloaded as usual.
