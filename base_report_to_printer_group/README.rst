This module adds printing groups to **base_report_to_printer**. A
printing group gathers users and the printers they work with, and
carries the specific printing actions of the reports for all its
members, so the printing behaviour is configured once per team instead
of once per user. With **base_report_to_printer_select**, the printers a
member is asked to choose from are narrowed down to the printers of
their groups.

Configuration
=============

To configure this module, you need to:

1. Go to *Settings > Technical > Printing > Printing Groups* and create
   a group, for example *Warehouse*.
2. Add its members on the **Users** tab. A user can belong to several
   groups; the users of a group can also be edited from the **Printing
   Groups** field on the user form.
3. Optionally list the printers of the team on the **Printers** tab.
   When a report asks the user to select a printer, members only see the
   printers of their groups. An empty list does not restrict them.
4. On the **Report actions** tab, add one line per report with the
   behaviour and printer to use for the members of the group. The same
   lines can be added from the report form, in *Specific actions per
   user*, by filling in **Printing Group** instead of **User**.

Usage
=====

When a user prints a report, the printing behaviour is resolved in this
order:

1. The specific action of the user for the report.
2. The specific action of the first of the user's groups, by sequence,
   that has a line for the report.
3. The default behaviour and printer of the report.
4. The defaults of the user.

When the report asks the user to select a printer, the dialog proposes
the printers of the user's groups that support the paper format of the
report. **See more** reveals the other printers of that paper format,
outside the user's groups; printers of another paper format are never
offered.
